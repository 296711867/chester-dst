# DST 服务器查询 · 协议逆向记录

> 📦 Chester 深入文档 · [← 返回 README](../README.md)
> 逆向对象:`dst/dontstarve_steam_x64.exe`(客户端)与 `dontstarve_dedicated_server_nullrenderer_x64.exe`(专用服)
> 产出工具:根目录 `dst_servers.py`(免登录查询在线服务器)

## 0. 一句话结论

游戏内服务器列表来自 **Klei lobby-v2 服务**:专用服开机后向 `lobby-v2.klei.com` 注册,
客户端按大区拉取列表。原接口查询需游戏内登录票据(直接访问 CDN 列表路径返回 403),
社区镜像 **dstserverlist.top** 提供了同数据的公开 API,字段与游戏浏览器完全一致,
本项目的 `dst_servers.py` 即基于它实现免登录查询。

## 1. 逆向过程

| 步骤 | 手段 | 发现 |
|---|---|---|
| 1 | 客户端/专用服 exe 字符串挖掘 | `RequestLANServerList` / `GetServerListing` / `SendHandShakeServerListing` / `DeserializeHandShakeServerListing` —— 自建列表系统,非标准 Steam 浏览接口 |
| 2 | 域名串挖掘 | **`lobby-v2.klei.com`**(查询/注册)、**`lobby-v2-cdn.klei.com`**(CDN 分发),另有 `accounts.klei.com`(专用服登录)、`cdn.klei.com` |
| 3 | CDN 路径提取 | `lobby-v2-cdn.klei.com/regioncapabilities-v2.json` → 4 个大区:`us-east-1` / `eu-central-1` / `ap-southeast-1` / `ap-east-1` |
| 4 | 列表路径探测 | CDN 上 `/list`、`/lobby-v2/list` 等返回 **403**(存在但需游戏票据);`lobby-v2.klei.com` 未带票据一律 404 |
| 5 | 字段名挖掘 | `max_players` / `game_mode` / `season` / `intent` / `tags` / `guid` / `platform` / `__token` —— 与公开镜像响应字段一一对应,证实镜像就是 lobby-v2 数据 |
| 6 | 社区实现 | dst-skins-checklist 同作者的姊妹项目 **ilyfairy/dst-server-list**(dstserverlist.top),前端构建产物中提取出完整 API 契约 |

## 2. 可用接口(dstserverlist.top 公共镜像)

基址:`https://api.dstserverlist.top`,全部 **POST + JSON**。注意:该接口偶发瞬时 SSL 中断,重试 2-3 次即可(工具已内置)。

### 2.1 列表 `POST /api/v2/server/list`

请求体(全部可选):
```json
{
  "ServerName": {"Value": "永恒", "IsExclude": false, "IsRegex": false},
  "PlayerName": {"Value": "角色名", "IsExclude": false, "IsRegex": false},
  "Sort": ["-Connected"],          // +/- 前缀升降序;字段:Connected/Days/ServerName/PlayerName/Season…
  "PageCount": 20, "PageIndex": 0  // 分页,页码从 0 起
}
```
响应:`{DateTime, LastUpdate, Count, TotalCount, PageIndex, MaxPageIndex, List:[…]}`。
List 元素字段:`Name` / `Address{IP,IsoCode}` / `Port` / `RowId`(=房主 KU_) / `Connected` /
`MaxConnections` / `Mode`(survival/endless/wilderness) / `Intent`(survival=生存, endless=无尽…)
/ `Season` / `IsPvp` / `IsPassword` / `IsMods` / `IsDedicated` / `IsClanOnly` / `IsFriendsOnly` /
`Version` / `Session` / `SteamId` / `LobbyRegion` / `Tags` / `Secondaries`(从服列表)…

### 2.2 详情 `POST /api/v2/server/details?id=<RowId>&forceUpdate=false`

注意 `id/forceUpdate` 走 **查询串**(请求体为空)。返回 `Server:{}`:
`Players[{Name,NetId(SteamID),Color}]`(在线玩家)、`DaysInfo{Day,DaysElapsedInSeason,DaysLeftInSeason,TotalDaysSeason}`
(游戏天数/季节进度)、`ModsInfo[{Name,CurrentVersion,NewVersion}]`(MOD 清单及更新状态)、`Tick`、`Nat` 等。

### 2.3 其他

- `POST /api/v2/server/GetTotal` → 全服总览 `{Servers, Connections, Version, DateTime}`(如 10240 台 / 6514 人);
- `POST /api/v2/server/GetTags` body `{min:N}` → 出现次数 ≥N 的标签;
- `POST /api/v2/server/GetPrefabs` → 地图(prefab)清单;
- `POST /api/v2/mods/QueryMods|GetModsInfo|GetUsageNames` → 服务端 MOD 检索。

## 3. 现成工具

```
python dst_servers.py                        # 按在线人数列前 20 台
python dst_servers.py --search 永恒           # 按名字搜(支持中文服名)
python dst_servers.py --mode survival --size 10
python dst_servers.py --info KU_xxxx         # 单服详情:在线玩家/MOD/天数
python dst_servers.py --total                # 全服总览
```

## 5. 原始协议(Klei lobby-v2,据 DstServerQuery 开源实现还原)

[ilyfairy/DstServerQuery](https://github.com/ilyfairy/DstServerQuery) 是 dstserverlist.top 背后的
C# 协议库,直接从 Klei 服务器拉全量数据(引用 SteamKit/NeoLua)。从其 `LobbyDownloader.cs`
还原出的原始接口:

**大区能力表(免鉴权)**
```
GET https://lobby-v2-cdn.klei.com/regioncapabilities-v2.json
→ {"LobbyRegions":[{"Region":"us-east-1"},{...}]}
```

**列表(批量简报,其默认配置走自建代理;Klei 原始形态为 CDN 批量文件)**
- 代码注释中的 Klei 原始形态:`https://lobby-v2-cdn.klei.com/{Region}-{Platform}.json.gz`
  (如 `v2-ap-east-1-Steam.json.gz`,gzip JSON `{"GET":[简报...]}`)
- 实测当前直连返回 403(鉴权要求不明);其默认配置改走 `LobbyProxyTemplate` 代理

**单服详情(需要开服 Token)**
```
POST https://lobby-v2-{region}.klei.com/lobby/read     (如 lobby-v2-ap-east-1.klei.com)
Content-Type: application/json
{
  "__gameId": "DontStarveTogether",
  "__token":  "<开服Token>",          // Klei 账号服务器配置页申请,无 Token 拿不到玩家/MOD 详情
  "query": { "__rowId": "<RowId>" }
}
→ {"GET":[LobbyServerDetailed...]}
```
响应即游戏浏览器详情页数据:Players(玩家+SteamID)、DaysInfo(天数/季节进度)、ModsInfo(MOD 清单)、
Nat/Tick 等;批量详情可把 `[{RowId,Region}]` 列表作为 body 交给代理批量处理。

**其它结论**
- 开服 Token:Klei 账号"游戏服务器"页申请的专用服务器 token,普通玩家没有——这是详情接口的门槛;
- 库依赖 SteamKit(Steam 协议)、NeoLua/MoonSharp(执行游戏 Lua 解析 cluster 串),可见其数据
  加工链之深,自研直接对等实现成本不小;
- 结论:日常查询用镜像 API(§2)即可;想彻底去第三方,可自部署 DstServerQuery.Web
  (`http://127.0.0.1:3000/api/list`,接口与 §2 兼容),把自己的实例当作"私有镜像"。

## 6. 备注

- Klei 原接口(lobby-v2)的列表查询需要游戏内登录票据;本工具不碰它,走公开镜像即可满足
  "看有哪些服/找某名字的服/看某服人数" 的全部需求;
- 镜像数据约 1 分钟延迟(`LastUpdate`),与游戏内列表的刷新节奏相当;
- 该第三方服务若不可用,可依据 §1 的协议链(Steam 主服务器 + A2S 查询)另起实现,本文档留作路标。
