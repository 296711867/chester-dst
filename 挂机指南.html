Chester:不开游戏,挂着领每周礼物

📦 项目代号「切斯特」——饥荒里那只随行礼物箱,你不在游戏,它替你收礼。

黑窗口/控制面板挂着 → 每 6 分钟自动心跳 → 有礼物自动领取 → token 自动续期。
全程只发与游戏完全相同的正规 HTTP 请求;不改游戏文件、不注入进程。

第 0 章 · 30 秒了解它

它做什么:替你向 Klei 服务器完成"我登录了 / 我还在玩"的心跳,每 360 秒一次; 有皮肤礼物掉落时自动回执、自动开礼入账;登录凭证(token)快过期时自动续期。

它不做什么:不启动游戏、不改游戏文件、不注入任何进程、(目前)黑窗口方式一次只挂一个账号(控制面板方式支持多账号,见第 8 章)。 挂机期间需要一个窗口/进程保持运行。

展开:原理一图流(可跳过) 
Steam 客户端(已登录)
   │ 取会话票据(steam_api64.dll,与游戏同款调用)
   ▼
POST login.kleientertainment.com/login/LoginViaSteam
   │ 返回 60 分钟 GameSessionToken(KU_ 账号凭证)
   ▼
每 360 秒 POST items.kleientertainment.com/clientitems/DST/Tick {"Token":…}
   │ 服务端按心跳推进掉落进度
   ▼
有礼 {"GiftReceived":{"Key":…}}
   ├─ 回执 VerifyGiftingReceipt
   ├─ GetAllItems 找 Context==3 的未开礼物
   └─ 逐个 SetItemOpened 开礼入账(周礼 PC 上限 8 个/周)
   ▼
token 到期前 TokenPurpose 续期(链式续期已实测成立)

第 1 章 · 环境自检(3 项)

① Python 3.8+,且必须是 64 位
打开 cmd(资源管理器地址栏输 cmd 回车即可),粘贴: 
python --version
python -c "import struct; print(struct.calcsize('P')*8)"
达标标志:第一条输出 Python 3.x.x,第二条输出 64。
没装/是 32 位:去 python.org 装 64 位版,安装时勾选 Add python.exe to PATH。 没有python命令时也可试 py -3 --version。
② Steam 客户端已运行并登录(不要求开 DST)
达标标志:任务栏右下角 Steam 图标在线(不是离线模式)。脚本只借你的登录态取票据, 不占用游戏、不与游戏冲突。
③ steam_api64.dll 能被找到
自动查找顺序:脚本同目录 → 上级目录 → 上级下的 dst\。 当前布局(klei_login-main 与 dst 同级)已就位,无需动作。
若报"找不到 steam_api64.dll":把项目文件夹和 dst 放同级,或用第 7 章的 --dll 指定完整路径。
三项都勾上就可以继续了。

第 4 章 · 礼物到账怎么确认

收到礼物时日志/面板会出现:🎁 心跳带礼物 → 回执 OK → ★ 领取礼物 物品名 (编号)。 礼物是皮肤,进游戏在物品栏/衣柜就能看到。

随时手动查未开礼物队列:

python klei_open_gifts.py --dry-run

控制面板的"礼物记录"卡片会展示全部已领记录(跨账号汇总、标注归属;每账号一个独立数据库,存于 credentials\accounts\KU_****\)。

关于神秘箱(MYSTERYBOX)

神秘箱不属于周礼心跳这套系统,默认不动。想开:控制面板/命令行加开箱开关, 命令行对应 python klei_open_gifts.py --open-boxes(走 OpenMysteryBox 接口)。

📌 周礼 PC 上限 8 个/周,领满后约 24 小时不再掉。 控制面板会自动"领满即停"(暂停心跳,滑动 7 天窗口恢复后自动继续),无需手动管。

第 6 章 · 故障排查矩阵(13 条)

遇到问题:先 Ctrl+F 搜日志关键词。控制面板用户:红色状态行 + 事件记录里同样能找到这些关键词。

#现象(可搜索关键词)原因怎么办
1'python' 不是内部或外部命令 / bat 闪退 exit code 9009 未装 Python 或没进 PATH装 64 位 Python 3.8+,勾选 Add to PATH,重开 cmd 验证
2FileNotFoundError: 找不到 steam_api64.dll DLL 不在三条自动查找路径上项目与 dst 放同级;或 --dll "完整路径"
3[WinError 193] 不是有效的 Win32 应用程序 32 位 Python 加载 64 位 DLL换 64 位 Python(第 1 章命令验证输出 64)
4SteamAPI_Init 失败：Steam 客户端未运行或未登录？ Steam 没开/没登录/离线模式启动 Steam 并登录后重跑;仍失败跑 python devtools/_probe_ticket.py 看 BLoggedOn
5GetAuthSessionTicket 失败 (handle=0x0 len=0) Steam 用户上下文偶发未就绪(已自动重试 5 次仍失败)重启 Steam 等 30 秒重跑;反复出现跑 devtools/_probe_ticket.py 采集证据
6LoginViaSteam 失败 HTTP=4xx 或登录后立刻 E_INVALID_TOKEN 票据被拒:账号未拥有 DST / 家庭共享受限确认该 Steam 账号库里有 DST;家庭共享换主号再试
7心跳鉴权失效 …E_INVALID_TOKEN 后跟 已续期/已重登 token 到期,正常自愈无需动作
8每轮都 已重登,循环失效 时钟漂移 / 代理出口不稳 / Steam 反复掉线Windows 时间同步;关 VPN 代理试;重启 Steam
9检测到未开礼物，自动清理 Context=3 队列 历史积压未开礼,自动清理中无需动作,清完自动恢复
10SetItemOpened 失败 / GetAllItems 失败 物品状态并发变化 / 物品服抖动下轮自动重试;持续出现手动跑 python klei_open_gifts.py
11Tick 网络错误: NETERR: … 断网 / DNS / 防火墙拦截检查网络后它会下轮自动重试;可用 python klei_heartbeat.py --once 复测
12挂了几天零礼物 周礼节奏由服务端决定(约 2 小时一个,周上限 8);或电脑睡眠了 正常;查 credentials\klei_gifts.log 或面板礼物历史;确认没睡眠、没领满
13换了 Steam 号,日志/面板还是旧 KU_ 旧 session 被复用,链式续期一直续旧账号删 credentials\.hb_auto_session.json 与 credentials\accounts\ 旧目录,切号重跑
把日志发给别人前,先抹掉 KU_ 号与 SteamID(第 9 章有脱敏提示)。

第 7 章 · 进阶用法

单独登录看凭证 / 续期 
python klei_steam_login.py
计划任务:每 30 分钟单轮心跳(不开常驻窗口)

任务计划程序 → 创建基本任务 → 触发器"每 30 分钟" → 操作"启动程序":

python klei_heartbeat_auto.py --once --no-logfile

起始位置填本项目文件夹。注意:计划任务的 --once 模式每次要用有效 token,断链时会自动 重登(需 Steam 在线)。

一键导入门户历史礼物(补齐接入前的记录)

控制面板「礼物记录 → 导入历史」,向导会自动探测你之前登录过的会话:

  1. 已连接 → 直接点一键导入(约 20~40 秒,有转圈和秒数提示)
  2. 未连接/已过期 → 点打开登录窗口,在弹出的浏览器里登录 Steam(密码不经过面板), 关窗后点我已登录,检测 → 一键导入

导入内容 = Klei 门户过去一年的官方逐笔记录(每日礼/周礼带周号),按官方时间戳回填, 重复导入零副作用;周礼 X/8 与每日礼状态随即与官方对齐。

清空 礼物记录卡右上角「清空记录」:两击确认, 自动备份到账号目录(gifts_backup_*.json),清空后一键导入即可恢复。

AI/脚本自动化管理(本地 API,推荐)

控制面板开着时,本机 http://127.0.0.1:8377 提供机器可读接口(仅本机可访问)。 定时任务/AI 只需一步:

curl http://127.0.0.1:8377/api/automation

返回运行状态、每账号周礼 X/8 与每日礼状态、待办清单 pending_actions—— 看到 "start" 就 POST /api/start,看到 "login"/"resume_paused" 就是需要人切 Steam 号,其余情况不用动。礼物历史可查 /api/gifts?source=daily&limit=50。完整决策表见 README「本地 API 与 AI 自动化」。

自定义心跳间隔(防风控:别低于 360) 
python klei_heartbeat_auto.py --interval 600

下限 30s 被强制抬回。社区实测缩短间隔可加快出礼(4-5h→1h),但属加速行为,风控自担。

指定 DLL 完整路径 
python klei_heartbeat_auto.py --dll "D:\你的路径\dst\steam_api64.dll"
单轮静默测试(不写日志文件) 
python klei_heartbeat_auto.py --once --no-logfile
票据诊断工具 _probe_ticket.py

拿不到票据时跑 python devtools/_probe_ticket.py,输出 Init/登录态/8 次重试明细; DLL 自动按主脚本顺序查找。诊断结论对照第 6 章 4/5 号条目。

第 8 章 · 多账号挂机(控制面板已支持)

原理:token 可链式续期(已实测 ≥2 跳),日常挂机只需纯 HTTP——不需要沙盒、 不需要多开 Steam。

添加一个新账号(人肉环节,每账号一次):打开控制面板 → 把 Steam 客户端 切换登录到目标账号 → 点「添加账号」(面板代为登录并存档)→ 勾选启用 → 开始挂机。 之后该账号日常自动续期,不再需要 Steam 在场。

日常规则:每轮按顺序处理所有勾选的账号(账号间错峰几秒);某账号领满 8/8 只暂停它自己; 账号不符(Steam 停在别的账号)也只暂停该账号——切好号后把该账号关再开勾选即重试。

链条断了:把 Steam 切回该账号重新「添加」一次即可,其它账号不受影响。详见 docs\多账号路线图.md 与 docs\情报-社区与SDK调研_2026-10-26.md。

多账号同 IP 请求频率的风控表现未知,默认节奏已错峰,请勿调快间隔。

第 9 章 · FAQ 与安全须知

会被封号吗?

未知。本工具只发与游戏完全相同的低频请求,但任何自动化 都违反服务条款的可能性存在,自担风险。别调快间隔、别多账号狂刷。

能和游戏同时开吗?

能。实测脚本运行期间开游戏 6+ 次无掉线无冲突 (Klei 会话追加式)。但控制面板和黑窗口 bat 别同时开(互相顶 token)。

几天没礼物正常吗?

正常。节奏约 2 小时一个、每周上限 8 个, 领满即停 24 小时+;面板会显示"本周 x/8"。

Token 泄露有多危险?

Token=你 Steam 账号的 Klei 登录凭证, 60 分钟自过期,但别外传;credentials\ 整个目录(会话/日志/数据库)都不要发给别人、 不要提交到任何仓库(已被 .gitignore 排除)。

日志分享前怎么脱敏?

抹掉所有 KU_…、SteamID (7656…开头数字)、pcl- 开头的 token 串。

想核对领到的皮肤?

皮肤即 Steam 物品,可用 Steam 公开库存 交叉验证:steamcommunity.com/inventory/<你的SteamID>/322330/2(浏览器直接开)。
